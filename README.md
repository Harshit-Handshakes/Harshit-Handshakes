### 👋 About Me

I lead engineering at **Handshakes**, a corporate intelligence platform that turns company registry data across Southeast Asia into due diligence, entity screening and ownership insights.

- 🏗️ **What I do:** technical architecture, API design, data platforms and product launches
- 🤖 **Current focus:** conversational AI agents and MCP integrations for corporate intelligence
- 👥 **Teams I work with:** Engineering, AI Research, Product, QA and UI/UX
- 🏦 **Domain experience:** Investment Banking, Core Banking, KYC and Corporate Intelligence
- 💼 **Previously:** S&P Global, Fiserv and HCL Technologies
- 🗄️ **Roots:** started in Oracle databases, now deep in SQL Server and AWS
- 🌏 **Location:** Singapore (GMT+8)

### 💡 Engineering Principles

> **Contracts first:** a clear API spec saves weeks of rework.
> **Agent-ready repos:** docs, skills and decisions live next to the code.
> **Trunk-based delivery:** small changes, shipped often, observed closely.
> **Security by default:** SBOMs, scanning and least privilege from day one.
